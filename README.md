# Gadget – Electronics Product Website

## About the Project
Gadget is an electronics product-based website developed as part of my college project. It allows users to explore electronic products through a simple interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Displays electronic products with images and details.
- Provides a user-friendly product browsing experience.
- Includes separate main website and admin pages.
- Offers easy navigation between website sections.
- Provides an admin interface for product management.
